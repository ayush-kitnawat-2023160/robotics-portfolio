COMPUTER VISION / FEATURE ANALYSIS

Wildlife classification & feature analysis.

Understanding not only which animal a model predicts, but how it organizes visual concepts.

01 / THE PROJECT

What was this about?

Trained image classifiers for ten wildlife species, then studied the learned representations with pretrained DINOv2 embeddings. The work combined practical supervised classification with an exploratory look into how feature spaces separate categories.

⌖
Project context

Ten-species wildlife image dataset and repeatable training experiments.

02 / OWNERSHIP

What I actually worked on.

My responsibilities — distinguished from everything the wider team or research project may have explored.

01

02

Applied image augmentation and transfer learning to improve robustness and generalization.

03

Extracted DINOv2 embeddings and explored category structure through t-SNE and K-Means clustering.

04

Tracked experiments, model variants and metrics using Weights & Biases.

04 / THE ENGINEERING

The problems & how I approached them.

The interesting part isn't just a working screenshot; it's the decisions behind the implementation.

01 / GENERALIZATION

A classifier can memorize the wrong visual cues

THE PROBLEM

Limited datasets and variable backgrounds can cause a model to depend on shortcuts rather than animal appearance.

MY APPROACH

Used augmentation, pretrained features and comparisons against simpler CNNs to investigate robustness.

Evidence / boundary: Training pipeline and augmentation experiments from the project summary.

02 / INTERPRETATION

Accuracy does not explain representation quality

THE PROBLEM

A class label says little about how the visual model arranges similar or dissimilar species internally.

MY APPROACH

Used DINOv2 features, t-SNE and K-Means to inspect structure in feature space.

Evidence / boundary: Feature-space analysis documented in the resume.

03 / EXPERIMENTS

Comparisons need repeatable records

THE PROBLEM

Without run tracking, architecture and augmentation changes are hard to compare fairly.

MY APPROACH

Logged training runs and metrics in Weights & Biases to retain experimental context.

Evidence / boundary: Experiment-management setup described in the resume.
